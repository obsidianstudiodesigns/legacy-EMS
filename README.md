# Legacy EMS — concept redesign

A concept redesign of [legacyems.co.za](https://legacyems.co.za/) by Obsidian Studio Designs. Not the official Legacy Emergency Medical Services website; pages carry a notice and `noindex`.

- Static HTML/CSS/JS, no build step needed to serve.
- Pages are generated from shared partials: edit `build.py`, then run `python build.py`.
- Hero lighting effect: `assets/js/site.js` (`LightRig`).
